Установка днс на отдельную ноду или на control plane, я ставлю на control plane
1. установка DNS (dnsmasq на control-plane)
apt update
apt install -y dnsmasq

2. конфиг
vim /etc/dnsmasq.conf
внизу пишем

interface=eth0
bind-interfaces
address=/cp1.lab/37.27.44.115 # это ip адрес контрол плейна
address=/w1.lab/89.167.2.156 # это ip адрес worker ноды 1
address=/w2.lab/37.27.43.207 # это ip адрес worker ноды 2
server=8.8.8.8
server=1.1.1.1
3. Отключить systemd-resolved
systemctl disable systemd-resolved --now
rm /etc/resolv.conf
echo "nameserver 127.0.0.1" > /etc/resolv.conf
4. Перезапуск
systemctl restart dnsmasq
systemctl enable dnsmasq


На воркер нодах делаем:
1. На каждой worker
systemctl disable systemd-resolved --now
rm /etc/resolv.conf
echo "nameserver 37.27.44.115" > /etc/resolv.conf
(где 37.27.44.115 — IP твоего DNS/control plane)

2. Проверить
nslookup cp1.lab
nslookup w1.lab
nslookup google.com
